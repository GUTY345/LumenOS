# 🌟 Lumen OS

> **"Light as Air. Brilliant by Design."**  
> **"ประมาณมาก. ออกแบบอย่างลงมืออาชีพ."**

**Lumen OS** คือระบบปฏิบัติการเดสก์ท็อป Open Source สายพันธุ์ใหม่ที่ผสานความสวยงามและความลื่นไหลของ **macOS** เข้ากับประสบการณ์การใช้งานสไตล์ **iPadOS** บนสถาปัตยกรรมไฮบริดที่ประหยัดทรัพยากรสูงสุด

- ✅ ปรากฏการณ์ใหม่สำหรับ **Developer, Gamer และผู้ใช้ทั่วไป**
- ⚡ เพิ่มประสิทธิภาพสำหรับ **Intel Core Ultra** และ **AMD Ryzen AI**
- 🧠 ระบบจัดการทรัพยากรอัจฉริยะ (`lumend`) พร้อม Game Mode และ Smart Battery Engine

---

## 🚀 ภาพรวม (Overview)

Lumen OS ออกแบบมาเพื่อแก้ปัญหาแบตเตอรี่และระบบพักของเดสก์ท็อป Linux บน Laptop x86_64 ให้ได้ประสบการณ์ระดับ **MacBook (Apple Silicon)**

### คุณสมบัติเด่นๆ (Key Features)

| หมวด | รายละเอียด | Category | Details |
|------|------------|----------|---------|
| 🔋 การจัดการพลังงาน | ใช้งานได้ยาวถึง **10–14+ ชั่วโมง** พร้อม Instant Wake & Smart Suspend | Power Management | Up to **10–14+ hours** of usage with Instant Wake & Smart Suspend |
| 🖥️ อินเทอร์เฟซ | ดีไซน์สไตล์ macOS พร้อม Floating Dock, Liquid Glass, และ Squircle Icons | UI/UX | macOS-style interface with Floating Dock, Liquid Glass, and Squircle Icons |
| 🎮 โหมดเกม | Game Mode พร้อม Direct Scanout, P-Core Locking และ In-Game Overlay | Gaming | Game Mode with Direct Scanout, P-Core Locking, and In-Game Overlay |
| 🛡️ ความปลอดภัย | ระบบหลายชั้น: Secure Boot, Read-Only OS, Sandboxing, และ Full Disk Encryption | Security | Multi-layered security: Secure Boot, Read-Only OS, Sandboxing, and Full Disk Encryption |
| 🛠️ การอัปเดต | A/B Dual Partitioning พร้อมอัปเดตอัตโนมัติและ Fail-Safe Rollback | Updates | A/B Dual Partitioning with automatic updates and fail-safe rollback |
| 📦 App Store | รองรับ Linux Apps (Flatpak), Android Apps (Waydroid), และ One-Click Dev Suites | App Store | Supports Linux Apps (Flatpak), Android Apps (Waydroid), and One-Click Dev Suites |

## 🤝 วิธีร่วมมือ (Contributing)

เรารักผู้ร่วมมือทุกคน! ไม่ว่าคุณคือนักพัฒนา, ผู้ออกแบบ, หรือผู้ใช้ทั่วไป  
We love contributors of all kinds! Whether you're a developer, designer, or everyday user.

1. ดูที่ [CONTRIBUTING.md](CONTRIBUTING.md) เพื่อเรียนรู้วิธีเริ่มต้น  
   Check out [CONTRIBUTING.md](CONTRIBUTING.md) to learn how to get started
2. เลือกงานจาก [Issues](https://github.com/GUTY345/LumenOS/issues) ที่มี Label เช่น `good first issue` หรือ `help wanted`  
   Pick an issue from [Issues](https://github.com/GUTY345/LumenOS/issues) labeled `good first issue` or `help wanted`
3. ทำงานและส่ง Pull Request ของคุณ  
   Work on it and submit your Pull Request
4. ทีมจะรีวิวและให้ข้อเสนอแนะ  
   Our team will review and provide feedback

> 💡 เคล็ดลับ: เริ่มจากอ่าน Issues ที่มี Label `documentation` หรือ `design` หากคุณยังไม่มีประสบการณ์เขียนโค้ด  
> 💡 Tip: Start with issues labeled `documentation` or `design` if you're new to coding
